# AI 学习笔记

一个不写代码也能看懂 AI 的学习系列。

这里没有公式堆砌，没有黑话轰炸，只有一套大白话的主线：**AI 的聪明到底是怎么来的**。每期围绕一个问题展开，用类比、反例和讨论把原理讲透。

## 课程目录

| 期数 | 主题 | 笔记 |
|---|---|---|
| 第 1 期 | AI 是怎么工作的：接词机制、注意力、对齐与追问机制设计 | [AI原理学习笔记](AI原理学习笔记.md) |

## 这个系列怎么读

每期笔记都遵循同一个结构：

1. **一个核心误解**——先拆掉脑子里想当然的错误图景；
2. **机制本身**——用生活类比讲清底层原理；
3. **从原理推导现象**——为什么 AI 会幻觉、会犯错、会有"脾气"；
4. **讨论与延伸**——学习过程中真实产生的追问，往产品设计和技术前沿方向延伸。
